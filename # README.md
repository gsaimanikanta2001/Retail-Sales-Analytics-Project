# Retail Sales Analytics & Business Intelligence Project

## Project Overview
This project is an end-to-end retail sales analytics and business intelligence solution developed using Python, SQL Server, and Power BI. The project focuses on analyzing retail sales performance, customer behavior, product profitability, and operational efficiency using a multi-page interactive dashboard.

## Tools & Technologies Used
- Python
- pandas
- NumPy
- Matplotlib
- SQL Server
- Power BI

## Dataset Information
The dataset contains 8,000+ retail sales records with customer, product, sales, shipping, and profitability information. The dataset was cleaned, transformed, and analyzed to generate business insights and visual dashboards.

## Key Analytics Performed
- Data Cleaning & Preprocessing
- Feature Engineering
- KPI Analysis
- Regional Sales Analysis
- Customer Segmentation
- Product Performance Analysis
- Discount Impact Analysis
- Quarterly Revenue Trend Analysis
- Operational & Shipping Analysis

## SQL Analysis
SQL Server was used to perform:
- KPI queries
- Aggregations
- GROUP BY analysis
- Revenue and profit analysis
- Customer and product insights

## Power BI Dashboards
The project includes:
1. Executive Overview Dashboard
2. Customer Insights Dashboard
3. Product & Operations Dashboard

## Key Business Insights
- North region generated the highest revenue and profit.
- Corporate customers represented high-value customer segments.
- Higher discounts reduced overall profitability.
- Q2 and Q3 showed stronger revenue performance.
- Same Day shipping generated slightly higher revenue and profit.

## Project Outcome
This project demonstrates practical skills in data analytics, business intelligence, SQL querying, dashboard development, and business insight generation using real-world analytics workflows.
